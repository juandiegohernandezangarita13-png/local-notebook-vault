# Local Notebook Vault

Aplicación local e independiente que combina la gestión de notas Markdown con un motor RAG privado para consultar y resumir documentos sin conexión a internet ni consumo de APIs de terceros.

## Requisitos

- Python 3.10 o superior
- [Ollama](https://ollama.com/) instalado y en ejecución en el sistema local
